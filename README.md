# Andy

Andy is an AI agent for small businesses. It answers customers on WhatsApp, Instagram and your website, books appointments, sells from your catalog, and opens a ticket when a person needs to step in. You can take over any conversation at any time.

**Try it:** [andypartner.com](https://andypartner.com) · **Docs:** [docs.andypartner.com](https://docs.andypartner.com)

## Use Andy from Claude (MCP)

Andy has a hosted MCP server. Connect Claude, Claude Code, Codex, Cursor or any other MCP client, then run your workspace by chat: read customer conversations, approve posts and update what your agents know.

- **Server URL:** `https://app.andypartner.com/api/mcp` (Streamable HTTP). You sign in with your Andy account, so there is no API key to paste.
- **Needs:** an Andy workspace on the Pro Max plan.
- **Setup guide:** [andypartner.com/en/mcp](https://andypartner.com/en/mcp) · en español: [andypartner.com/mcp](https://andypartner.com/mcp)

The server is listed in the [official MCP Registry](https://registry.modelcontextprotocol.io) as `io.github.Andesphere/andy`.
